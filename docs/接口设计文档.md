## 1. 服务配置信息

### 1.1 服务地址

| 环境 | 地址 | 端口 |
|------|------|------|
| 开发环境 | `http://localhost` | `8000` |
| 生产环境 | `http://39.105.7.90` | `8000` |

**完整基础路径**: `http://{host}:{port}/api`

### 1.2 认证方式

| 项目 | 说明 |
|------|------|
| **认证类型** | JWT Bearer Token |
| **Header 格式** | `Authorization: Bearer <token>` |
| **Token 有效期** | 24小时 |
| **JWT Secret** | 环境变量配置（不对外暴露） |

### 1.3 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1686873600
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `code` | Integer | 状态码，200 表示成功 |
| `message` | String | 响应消息 |
| `data` | Object/Array | 响应数据 |
| `timestamp` | Integer | 响应时间戳（毫秒） |

### 1.4 错误响应格式

```json
{
  "code": 401,
  "message": "认证失败",
  "data": null,
  "timestamp": 1686873600
}
```

| 状态码 | 说明 |
|--------|------|
| 400 | 请求参数错误 |
| 401 | 未认证或 Token 无效/过期 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 409 | 资源冲突 |
| 500 | 服务器内部错误 |

## 2. 认证接口

### 2.1 用户登录

| 属性 | 值 |
|------|-----|
| **路径** | `/api/auth/login` |
| **方法** | `POST` |
| **认证** | 无需认证 |
| **功能** | 用户登录系统，获取 JWT Token |

**请求体** (`application/json`):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `username` | String | 是 | 用户名 |
| `password` | String | 是 | 密码（明文） |

**请求示例**:

```json
{
  "username": "zhangsan",
  "password": "password123"
}
```

**成功响应** (200):

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | String | JWT Token |
| `user_id` | String | 用户唯一ID |
| `username` | String | 用户名 |
| `can_import` | Boolean | 是否拥有导入权限 |

**响应示例**:

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "user_id": "60d21b4667d0d8992e610c87",
    "username": "zhangsan",
    "can_import": true
  },
  "timestamp": 1686873600
}
```

**失败响应** (401):

```json
{
  "code": 401,
  "message": "用户名或密码错误",
  "data": null,
  "timestamp": 1686873600
}
```

## 3. 导入接口

### 3.1 上传文件导入

| 属性 | 值 |
|------|-----|
| **路径** | `/api/import/upload` |
| **方法** | `POST` |
| **认证** | JWT Token + 导入权限 |
| **功能** | 上传文档文件，触发导入流程（支持多文件并发） |

**请求体** (`multipart/form-data`):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `files` | File[] | 是 | 待导入的文件列表 |

**支持文件格式**:
- PDF (.pdf)
- Markdown (.md)
- PPTX (.pptx)
- DOCX (.docx)
- TXT (.txt)
- 图片 (.jpg, .png, .gif)

**成功响应** (200):

| 字段 | 类型 | 说明 |
|------|------|------|
| `task_ids` | String[] | 任务ID列表，每个文件对应一个任务 |

**响应示例**:

```json
{
  "code": 200,
  "message": "导入任务已创建",
  "data": {
    "task_ids": [
      "task-abc123",
      "task-def456",
      "task-ghi789"
    ]
  },
  "timestamp": 1686873600
}
```

**失败响应** (403):

```json
{
  "code": 403,
  "message": "无导入权限，请联系管理员开通",
  "data": null,
  "timestamp": 1686873600
}
```

---

### 3.2 查询导入进度（SSE）

| 属性 | 值 |
|------|-----|
| **路径** | `/api/import/progress/{task_id}` |
| **方法** | `GET` |
| **认证** | JWT Token |
| **功能** | 通过 Server-Sent Events 订阅导入进度 |

**路径参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `task_id` | String | 任务ID |

**SSE 事件格式**:

```json
{
  "event": "progress",
  "task_id": "task-abc123",
  "status": "running",
  "progress_percentage": 42,
  "done_list": ["node_entry", "node_pdf_to_md", "node_md_img"],
  "running_list": ["node_document_split"],
  "timestamp": 1686873600
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `event` | String | 事件类型，固定为 `progress` |
| `task_id` | String | 任务ID |
| `status` | String | 状态：`running`/`completed`/`failed` |
| `progress_percentage` | Integer | 进度百分比（0-100） |
| `done_list` | String[] | 已完成的节点列表 |
| `running_list` | String[] | 当前运行的节点列表 |

**完成事件示例**:

```json
{
  "event": "progress",
  "task_id": "task-abc123",
  "status": "completed",
  "progress_percentage": 100,
  "done_list": ["node_entry", "node_pdf_to_md", "node_md_img", "node_document_split", "node_item_name_recognition", "node_bge_embedding", "node_import_milvus"],
  "running_list": [],
  "result": {
    "file_name": "Python基础课程.pdf",
    "chunk_count": 42,
    "item_names": ["Python基础", "Python入门"]
  },
  "timestamp": 1686873600
}
```

## 4. 查询接口

### 4.1 发起查询

| 属性 | 值 |
|------|-----|
| **路径** | `/api/query` |
| **方法** | `POST` |
| **认证** | JWT Token |
| **功能** | 用户发起知识库查询，支持流式响应 |

**请求体** (`application/json`):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question` | String | 是 | 用户问题 |
| `session_id` | String | 否 | 会话ID，不传则新建会话 |
| `confirmed_item_names` | String[] | 否 | 已确认的主体名称列表（二次请求时携带） |

**请求示例**:

```json
{
  "question": "Python有哪些课程？",
  "session_id": "session-abc123"
}
```

**成功响应** (200): `text/event-stream`

**SSE 事件类型**:

| 事件类型 | 说明 |
|----------|------|
| `status` | 流程状态更新 |
| `item_names_choice` | 需要用户确认主体名称 |
| `answer` | 答案内容（流式输出） |
| `done` | 查询完成 |

**状态事件示例**:

```json
{
  "event": "status",
  "data": {
    "status": "processing",
    "step": "node_search_embedding",
    "message": "正在检索知识库..."
  }
}
```

**主体名称选择事件示例**:

```json
{
  "event": "item_names_choice",
  "data": {
    "confirmed_item_names": [],
    "optional_item_names": ["Python基础", "Python进阶", "Python数据分析"],
    "question_rewritten": "Python相关课程有哪些"
  }
}
```

**答案事件示例**:

```json
{
  "event": "answer",
  "data": {
    "content": "根据知识库内容，Python相关课程包括：",
    "session_id": "session-abc123",
    "message_id": "msg-789",
    "item_names": ["Python基础", "Python进阶"]
  }
}
```

**完成事件示例**:

```json
{
  "event": "done",
  "data": {
    "session_id": "session-abc123",
    "message_id": "msg-789",
    "total_time": 3500,
    "sources": [
      {
        "file_title": "Python基础课程",
        "content": "Python基础课程介绍...",
        "score": 0.92
      }
    ]
  }
}
```

### 4.3 确认主体名称

| 属性 | 值 |
|------|-----|
| **路径** | `/api/query/session/{session_id}/item-confirm` |
| **方法** | `POST` |
| **认证** | JWT Token |
| **功能** | 用户确认主体名称后，继续查询流程 |

**路径参数**:

| 参数 | 类型 | 说明 |
|------|------|------|
| `session_id` | String | 会话ID |

**请求体** (`application/json`):

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `confirmed_item_names` | String[] | 是 | 用户确认的主体名称列表 |
| `question` | String | 是 | 原始问题 |

**请求示例**:

```json
{
  "confirmed_item_names": ["Python基础", "Python进阶"],
  "question": "Python有哪些课程？"
}
```

**成功响应** (200): `text/event-stream`

响应格式同 `POST /api/query`，直接进入检索流程，跳过主体名称确认步骤。

## 6. 数据模型定义

```python
# app/api/schema/auth_schema.py
from pydantic import BaseModel, EmailStr
from datetime import datetime
from typing import Optional

class User(BaseModel):
    user_id: str
    username: str
    can_import: bool
    created_at: datetime
    last_login: Optional[datetime]
```

```python
class LoginRequest(BaseModel):
    username: str
    password: str
```

### 6.3 登录响应模型 (LoginResponse)

```python
class LoginResponse(BaseModel):
    token: str
    user_id: str
    username: str
    can_import: bool
```

### 6.4 查询请求模型 (QueryRequest)

```python
# app/api/schema/query_schema.py
from pydantic import BaseModel
from typing import Optional, List

class QueryRequest(BaseModel):
    question: str
```

```python
class Message(BaseModel):
```

```python
class SessionHistoryResponse(BaseModel):
```

## 8. 错误码汇总

| 错误码 | HTTP状态码 | 错误信息 | 说明 |
|--------|-----------|----------|------|
| 400 | 400 | 请求参数错误 | 参数格式或内容不正确 |
| 401 | 401 | 未认证或 Token 无效 | 需要登录或 Token 已过期 |
| 403 | 403 | 无权限访问 | 用户没有对应的操作权限 |
| 404 | 404 | 资源不存在 | 请求的资源未找到 |
| 409 | 409 | 资源冲突 | 文件已存在等冲突情况 |
| 500 | 500 | 服务器内部错误 | 服务器处理异常 |

## 10. 安全注意事项

1. **JWT Token 安全**
   - Token 存储在前端 localStorage 中
   - 请求时通过 Authorization Header 携带
   - 登出时将 Token jti 加入黑名单

2. **密码安全**
   - 密码使用 bcrypt 哈希存储
   - 登录接口仅接收 HTTPS 请求

3. **权限校验**
   - 导入接口需要额外校验 `can_import` 权限
   - 所有接口都需要验证用户身份

4. **文件上传安全**
   - 限制文件大小和格式
   - 文件存储路径不暴露给前端

5. **SSE 连接安全**
   - SSE 连接也需要携带 Token
   - 设置合理的连接超时时间

## 附录：FastAPI 路由注册示例

```python
# app/api/http/main_server.py
from fastapi import FastAPI
from app.api.http import auth_routes, import_routes, query_routes

app = FastAPI(title="教育知识库 API", version="1.0")

# 注册路由
app.include_router(auth_routes.router, prefix="/api/auth", tags=["认证"])
app.include_router(import_routes.router, prefix="/api/import", tags=["导入"])
app.include_router(query_routes.router, prefix="/api/query", tags=["查询"])

# 静态文件服务
from fastapi.staticfiles import StaticFiles
app.mount("/", StaticFiles(directory="app/resources/html", html=True), name="static")
```
