### 2.3 交互说明

| 交互 | 说明 |
|------|------|
| 登录/注册切换 | 点击标签切换表单，不刷新页面 |
| 登录成功 | 将 `access_token` 存入 `localStorage`，跳转到查询页 |
| 登录失败 | 输入框下方显示红色错误提示："用户名或密码错误" |
| 注册成功 | 自动切换到登录标签，显示绿色提示"注册成功，请登录" |
| 注册失败(409) | 用户名输入框下方显示"用户名已存在" |
| Token 过期 | 任意请求返回 401 时，自动跳转登录页 |
| 密码强度 | 前端校验 6-100 字符，不满足时输入框变红 |
